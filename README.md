# India Air Quality Analysis & Prediction

An end-to-end data analysis and machine learning project exploring air-quality patterns across Indian cities using pollutant measurements and AQI data from 2015–2020.

The project progresses from data cleaning and exploratory analysis to feature engineering, regression, classification, and model evaluation.

## Project Overview

The main objectives of this project are to:

- Explore air-quality patterns across Indian cities and seasons
- Investigate relationships between pollutants and AQI
- Engineer useful features for machine learning
- Predict continuous AQI values using regression models
- Classify observations based on whether AQI exceeds 100
- Compare different machine learning approaches
- Evaluate model performance and generalisation

## Dataset

The original dataset used for this project is the **Air Quality Data in India (2015–2020)** dataset obtained from **Kaggle**.

The original dataset is **not included in this repository**.
